# SpeedSol — Trazabilidad de combustible en Perú

Pitch de gobierno de SpeedSol para Perú, adaptando la propuesta de control de
subsidios y ventas de combustible ya presentada a El Salvador al contexto
peruano (SCOP/PVO, FEPC, FISE, desvío a minería ilegal en Madre de Dios).

Single-file HTML, sin dependencias externas. Publicado vía GitHub Pages.
